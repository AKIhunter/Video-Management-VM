# 功能使用和操作手册

> 视频管理器：轻量级视频索引与查询 Web 管理器。本机/内网使用，浏览器访问 `http://localhost:8080`。

## 一、首页（浏览与筛选）

### 1. 搜索与筛选栏

| 控件 | 说明 |
|---|---|
| 分类下拉 | 按分类筛选（与白屏管理的分类字典、扫描分类共用同一份数据） |
| 状态下拉 | 未看 / 想看 / 在看 / 看完 |
| 年份 / 月份 | 按发布年月筛选（选年份会重置月份） |
| **标签筛选 ▾** | 点击弹出标签气泡，**多选、OR 逻辑**（满足任一即显示）；6~8 栏、每栏最多 12 行。**即点即筛**：勾选/取消的瞬间就生效并同步到右侧栏位，**无需点「应用」**（气泡里的「清空」也会立刻生效）；选中的标签以 chips 显示在右侧栏位，可单个 `×` 移除 |
| 评分 ≥ | 按最低评分筛选（**0~10 分制**） |
| 只看收藏 | 只显示收藏的作品 |
| **排序** | 评分 / 日期 / 标题 / 入库 / 收藏 等升降序（位于**标签筛选与月份筛选之间**） |
| 分页 | 上一页 / 下一页 / 每页数量（30/50 等） |

> **筛选栏会被记住**：所有筛选项（关键词、分类、状态、年月、标签、评分、收藏、排序、每页数量）存在浏览器**会话存储**里，
> 刷新页面后自动恢复；**关闭标签页或新开会话则清空**（即「除非切换了 session」）。
>
> **滚动自动翻页（滚轮 / 滚动条 / 缩放窗口都会触发）**：往下翻到接近列表底部（提前约 600px）就
> **自动加载并显示下一页作品**（严格沿用当前筛选栏的过滤与排序，不会跑出筛选范围）；首屏没铺满视口时也会自动补齐。
> 列表底部始终有一个「**加载更多**」按钮 —— 自动触发万一没生效，点一下也能继续（同样遵守筛选约束）。
> 为避免一次加载过多把页面拖卡，单次最多自动加载 600 部；到上限点按钮即可再追加一批。

### 2. 作品卡片与详情抽屉

- 点击卡片打开**详情抽屉**：大图（封面/视频帧）、评分、名称、日期、来源组、标签、简介、观看状态、个人评分、收藏（★）。
- 卡片右上角显示**最新评分**（0~10，1 位小数）：有用户评分时显示**多用户平均分**，没人评分时回退显示历史/简评分。
- 详情抽屉提供：播放（HTTP Range 流式）、下载、本地播放器打开（大文件守卫）、编辑标签、写笔记。

#### 评分（0~10 分，共 10 颗星）

- 详情抽屉的「我的评分」**只有点星一种方式**：**点第 N 颗星 → 前 N 颗一起亮起，本次得分 = N**。
- 每个用户对每个作品**只能有一条评分**，重复评分会**覆盖**上一次的结果（不会出现两条）。
- 评分提交后**立即写入后端**并刷新卡片上的最新评分；后端还会在**没有长任务运行时**统计各作品的多用户平均分。
- 想取消自己的评分：**再点一次当前最高的那颗星**即可清除（清除后回退显示历史分）。

### 3. 消息通知（右上角 🔔）

- 任务完成 / 取消 / 失败、服务重启等会推送通知；小红点提示未读，点击查看详情（`logs.html?{id}` 看完整日志），可单条已读 / 全部已读。

## 二、播放页与推荐轮播（player.html）

从首页卡片详情抽屉点「播放」进入（新标签页打开 `player.html?id=…`）。

### 1. 播放窗口与右侧「关联作品」栏
- 上半区左右两栏：左边是播放器，右边是「**关联作品**」列表 —— 按**名称高度相似**与**所在文件夹（同目录）**
  罗列出的其它作品（同目录 = 同系列分卷，通常最相关）。点击任意一项**在当前页面快速切换播放**（不跳页）。
- **列表固定**：关联列表在**首次打开播放页时查询一次并固定**；切换播放列表内其它作品时**不会重新查询**
  （推荐轮播仍按当前作品正常刷新）。
- **排位与标记**：列表**第一位始终是当前播放的作品**并带「正在播放」特殊标记；
  切换到其它关联作品时，标记跟随移动到新的播放项。
- **高度与滚动**：列表高度**不超过视频播放器高度**（随播放器高度自动调整）；**单列**展示，
  每项**宽高统一**，作品名超长显示「…」（悬停有气泡显示完整名称）；
  内容多时列表出现**纵向滚动条**，支持鼠标滚轮上下滑动或拖动滚动条翻阅。
- **条目内容**：只展示作品**原有的标签**（不展示「同目录」等推导信息）＋「正在播放」标记。
- **自动连播**：当前视频播放结束（`ended`）后，按固定列表顺序自动播放当前作品的下一个（到末尾即停止）。
- **格式支持**：mp4 / mkv / webm / mov 等浏览器原生格式直接流式播放；**avi / wmv / flv / rmvb / mpg 等**
  由服务器用 **ffmpeg 实时转码**为可流式的分片 mp4（H.264+AAC，720p）—— 能正常观看，
  但转码流**不支持拖动进度条**，播放器上方会有提示。
- **大文件守卫**：**仅超过 2GB** 的视频会建议「本地播放」（阈值可在 `config.json` 的
  `memory_guard_bytes` 调整）；未超过则直接在线播放。
- 音量跨作品、跨页面记忆（localStorage）。
- 顶栏显示文件名与 `#索引ID`。

### 1.1 播放器下方的作品信息条（名称 / 评分 / 收藏 / 标签）

| 元素 | 说明 |
|---|---|
| **作品名称** | 取自索引库的作品名（顶栏显示的是文件名，两者可能不同） |
| **目前评分** | 0~10 分制，1 位小数；有用户评分时显示**多用户平均分**，没人评分时显示历史/简评分，都没有则「暂无评分」 |
| **收藏按钮** | 点一下收藏、再点取消（每账号一条记录），状态即改即存 |
| **标签** | 以 chips 列出当前作品的标签；右侧输入框可直接添加（有词典联想，回车或点「添加」提交） |

- **标签权限**：**管理员（admin）可增可删**（每个标签上带 `×`）；**其余账号只能增加、不能删除**
  —— 非管理员看不到 `×` 按钮，后端删除接口也会拒绝（403）。
- **我的评分（打星）**：信息条下方一排 **10 颗星**，点第 N 颗 = 打 N 分（0~10），前 N 颗自动亮起；
  **再点当前最高星即清除**。评分后大分数和「N 人评分」立即刷新（后端已即时重算均值）。
- 通过推荐轮播切换作品时，这条信息会随之刷新。

#### 键盘快捷键（播放页，输入框内输入时不生效）

| 按键 | 作用 |
|---|---|
| `←` / `→` | 视频**快退 / 快进 15 秒** |
| `Ctrl + ←` / `Ctrl + →` | 快退 / 快进 **30 秒** |
| `↑` / `↓` | 音量 **+5% / −5%**（同步保存到音量记忆） |

每次操作屏幕下方会有短暂提示（快进/快退秒数、当前音量百分比）。
方向键已改为控制视频，轮播翻页请用两侧箭头按钮、底部圆点、自动轮播或「换一批」。

### 2. 推荐轮播（每页 2 行 × 6 列 = 12 格，不滚动）

> 整个轮播区按 **1.3 倍**放大显示（卡片、文字、按钮同步放大），可视宽度仍与播放器区域一致。

| 元素 | 位置 / 行为 |
|------|------------|
| 卡片 | 点击即**在本页切换播放**（不跳页、不刷新），当前播放项描边高亮 |
| 封面角标 | 右上 ★评分；左上无；封面用 `contain` 渲染，**不放大不失真** |
| **卡片内容** | 一级标题=**作品名称**（超长省略号）；次级=**标签**；小字=**日期**（年月）。缩略图高度为原 1.5 倍，尽量多展示图片 |
| **标签徽章** | 卡片下方展示与当前作品**共有的具体标签**（最多 3 个，超出用 `+N` 折叠）；无共有标签时退回显示时长 |
| 自动轮播 | 默认开启，每 8 秒翻一页；鼠标悬停或键盘聚焦时**自动暂停**，离开后恢复；按钮可手动开关（记忆到 localStorage） |
| 翻页箭头 | 轮播两侧 `‹ ›`；只有一页时自动隐藏 |
| 圆点指示 | 底部圆点，点击直接跳页；下方显示「第 x / y 页」 |
| 换一批 | 用同样的打分规则换一个随机种子重新挑，推荐结果变化但质量不变 |
| 键盘 | `←`/`→` 视频快退/快进 15 秒（按住 `Ctrl` 为 30 秒）；`↑`/`↓` 音量 ±5%。轮播翻页用箭头按钮 / 圆点 / 自动轮播 / 换一批 |

> 说明：**来源组（studio）不再展示**（也不显示「同制作组 / 同期作品 / N 个相同标签」这类模糊文案）。
> 来源组仍参与**打分与多样性约束**，只是不出现在卡片上。

### 3. 推荐逻辑（为什么是这些作品）

按 8 个因子加权打分后排序，**分数越高越靠前**：

1. **标签重合度**（权重最高）——与当前作品共享标签越多越靠前；
2. 同分类；3. 年代接近；4. 评分更高；5. 未看优先（看完的降权）；
6. 新入库小幅加成；7. 少量随机扰动，让「换一批」有新鲜感。

**只会推荐同一分类**：真人只推真人、视频只推视频（分类来自分类字典，**以后新增分类同样自动生效**，
无需任何配置）。同分类下没有其他作品时才会放开到其它分类兜底，避免轮播空白。

第 1 页是最相关的一批，第 2、3 页逐步降低相关度、增加探索；每页还限制了**同一来源组最多 3 格**，防止一个系列包场。

> 无障碍与响应式：支持 `prefers-reduced-motion`（系统开启减弱动效时默认不自动轮播）；窄屏自动降为 4 / 3 / 2 列，保证卡片可读。

## 三、白屏管理（页眉右上角「白屏管理」）

> 页眉右上角自左向右依次是：🔔 消息通知、**个人中心**、**白屏管理**、**管理中心**。
> 管理中心按钮已从页面底部移到「白屏管理」右侧。

### 0. 个人中心（页眉「个人中心」）

- **账号与签到**：展示账号名 / 角色 / 等级（Lv）/ 成长值进度条 / 累计与连续签到天数。
  「**每日签到**」每天一次：+10 成长值，**连续每满 7 天额外 +20**（断签重新计连续天数）；
  每 100 成长值升 1 级（上限 30 级）。
- **我的收藏**：当前账号收藏的作品卡片墙，点击直接打开详情抽屉。
- **等级权益（预留）**：未来按等级开放部分功能的窗口 —— 后端已备好
  `services/levels.py :: FEATURE_LEVELS + can_use()` 门槛接口，当前**尚未启用任何等级限制**。

### 0.1 管理中心 · 账号管理（增删改查）

- **新增账号**：输入账号名 + 选择角色（管理员 / 普通用户）→「新增账号」。
- **改名 / 改角色**：每行直接编辑，点「保存」生效。
- **删除账号**：会同时清掉该账号的观看状态 / 评分 / 收藏 / 备注（不影响作品与标签）。
- 保护：**默认登录账号（标「默认」）不可删除、不可降级为普通用户**（防止失去管理权限）。

进入后按标签页切换各功能：

### 1. 作品编辑

- **查询**：按关键词（标题/来源组/索引ID）、分类、封面/简介/标签是否有值、标签关键字、年份筛选。
- **下载索引ID.txt**：导出**当前查询结果**的作品索引ID（每行一个 id；不设条件 = 导出全部）。供联网补全 A 区「解析ID」使用。
- **编辑**：选择作品后填写标题/日文原题/**来源组**/年份/日期/评分（**0~10 分**）/字幕/简介/**标签**/文件地址/海报地址，保存。
  **来源组**（`studio` 字段）由扫描自动生成：`上级文件夹/本级文件夹`（上级为数据盘根 MediaLibrary 时仅记本级），
  每次人工扫描导入后自动写入，替换旧「制作组」语义；也可手动修改。
  - **标签输入框**：点击会弹出标签气泡（多选），应用后写回输入框，可继续手动编辑。
  - **本作品联网补全候选**：联网拉取该作品的简介/标签建议，可「采用并入库」。
- **删除作品（索引+文件）**：把当前编辑的作品**连同磁盘上的视频文件一起删除**（**二次确认**，不可恢复）；
  服务端缓存里的封面会一并删除，素材目录里的海报会保留并在结果中列出。

### 2. 作品管理

- **分类管理**：当前分类下拉 + 新增 / 重命名（同步更新该分类下所有作品）/ 删除（仅允许删空分类）。
- **重复作品检测**：选一个分类 + 相似度阈值（默认 `0.86`，越大越严格），点「检测相似作品」，
  会把**标题高度相似**的作品自动分到一组（归一化后完全相同的标题一定同组）。
  - **逐组处理**：结果一次只展示**一组**（上方显示「第 X / Y 组」），用「‹ 上一组 / 下一组 ›」翻组；
    **删除只作用于当前展示的这一组**。
  - **勾选逻辑**：组头勾选框 = 本组**全选 / 全不选**；**不勾选的作品完全不受删除影响**，勾选了才会被删。
  - **两种删除**：「删除本组选中索引」只删索引与关联数据（磁盘文件不动，误删重扫可恢复）；
    「**删除本组选中作品（含文件）**」会把勾选作品的**视频文件从磁盘一并删除**（**二次确认**，不可恢复，谨慎使用）。
  - **本组忽略**：每组右上角有「本组忽略」按钮，点过后该组**以后不再被检测出来**
    （记录的是组内标题：组里条目被删掉仍然生效，标题改掉则自然失效）。
  - 发现组数过多时说明阈值偏松，可调高后重新检测；单次最多扫描 5000 部，超出请分分类检测。
- **作品列表**：按分类 + 模糊查询（索引ID / 作品名称 / 标签）；「重置」= **清空展示列表**（不重新查询）。
- **批量操作**（表头复选框全选当前列表，或逐行勾选）：
  - **删除选中索引**：仅从项目移除索引，**绝不删除磁盘文件**（重扫可恢复）。
  - **批量打标签**：弹出标签气泡多选，追加标签（保留原有、每作品 ≤10 个）。
  - **移动到分类**：把选中作品改到另一分类。

### 3. 联网补全

#### A · 全量联网补全
- 对缺失的作品自动回填**发布年月 / 简介 / 标签**（联网题材优先 → 本机简评兜底）。
- 可**上传索引ID文件**限定范围（不上传 = 全量缺失补全）；解析出的 ID 供 B 区复用。
- 尊重 `edited_fields` 人工编辑保护：已人工编辑过的字段**永不覆盖**。

#### B · 封面补全
- ① **本地匹配**：匹配库内 海报/封面/COVER/预告 目录素材。
- ② **联网搜索封面**：逐作品联网抓取下载（**必须先在 A 区解析索引ID**，否则提示步骤）。
- ③ **指定目录补全**：填本地目录，取图片与缺封面作品按标题匹配（只记录路径引用）。
- ④ **服务端抽帧**：用 **ffmpeg** 给缺封面的作品抽帧落盘小图、写回封面，之后前端改走普通图片加载（**首屏加载更快**）。
  与 ② 相同，**必须先在 A 区解析索引ID**，只处理解析范围内当前没有封面的作品。
  （旧版「④ 截图视频封面（标记）」已移除，由本功能替代；历史上标记过的作品仍能正常显示，抽帧成功后标记自动清除。）

#### C · 人工审定（双栏）
- 左栏作品名列表，点击后右栏展示候选素材（前 10 张）。
- **有效行为**：点击候选图即选中（左栏「待修改」→「已修改」）。
- **批量提交修改**：提交所有已选图的行，成功后从左栏移除。
- 「刷新列表」按 **B 区最近一次联网封面范围**筛选；「重置列表」只清视图。
- 「重搜…」「拒绝吗」在右栏翻页控件左侧，用于单条处理。

### 4. 扫描（两段式：扫描 → 人工确认 → 导入）

- **扫描不再直接写库**：扫描只产出「**待导入清单**」（新增 / 有变化的候选），在下方列表里逐条展示
  （类型、分类、作品名、年份、有无封面、文件路径），确认无误后点「**导入到索引**」才会入库。
- **导入防呆**：导入时必须选择具体分类 —— 上方「分类」下拉若还是「**自动（按目录名）**」会被拒绝并提示；
  导入前还会逐条二次校验文件仍在且未变化（消失 / 变动的条目自动跳过）。
- 「放弃清单」可清空暂存；清单只存于内存，**服务重启后自动清空**（重新扫一次即可）。
- **分类下拉**：扫描时可选「自动」；但**导入**必须选具体分类（导入到哪个分类由人工决定）。
- 全盘扫描需勾选确认（防误触）。
- ⚠️ 行为变化：扫描/导入都**不会自动移除「文件已消失」的旧索引**——需要清理时请用「作品管理」删除索引。

### 5. 标签管理

- **新增 / 改名 / 删除**标签（删除需输入标签名解锁，防误触）。
- **导出标签**：`id,标签值` 纯文本 CSV（UTF-8 带 BOM，Excel/记事本可直接打开）。
- **导入标签**：增量（只增不删）/ 覆盖（清空重建，需输入 `__OVERWRITE__`，服务端自动备份到 `backups/`）。
- **标签恢复**：误覆盖/乱码后诊断、清理乱码标签、按简评痕迹重建关联、重跑打标。

### 6. 一键重启

- 输入确认词 `__RESTART__` + 二次确认后重启服务（改后端代码后用它生效）。
- 重启期间按钮会置灰并显示「服务重启中…」；**页面会自动轮询服务状态，恢复后自动刷新**（最多等约 1 分钟），
  无需手动刷新浏览器。

## 四、关键约束（务必知晓）

1. **只删索引不删文件**：删除作品/移动分类只改数据库索引，磁盘文件永不改动。
2. **编辑字段防覆盖**：人工编辑过的字段记入 `edited_fields`，联网补全永不覆盖。
3. **每作品标签 ≤10 个**：批量打标签/导入时超出部分自动跳过。
4. **全盘扫描 / 一键重启 / 覆盖导入** 均有二次确认，防止误操作。
