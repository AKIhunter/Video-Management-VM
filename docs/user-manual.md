# 功能使用和操作手册

> 视频管理器：轻量级视频索引与查询 Web 管理器。本机/内网使用，浏览器访问 `http://localhost:8080`。

## 一、首页（浏览与筛选）

### 1. 搜索与筛选栏

| 控件 | 说明 |
|---|---|
| 分类下拉 | 按分类筛选（与白屏管理的分类字典、扫描分类共用同一份数据） |
| 状态下拉 | 未看 / 想看 / 在看 / 看完 |
| 年份 / 月份 | 按发布年月筛选（选年份会重置月份） |
| **标签筛选 ▾** | 点击弹出标签气泡，**多选、OR 逻辑**（满足任一即显示）；6~8 栏、每栏最多 12 行；选中的标签以 chips 显示在右侧栏位，可单个 `×` 移除 |
| 评分 ≥ | 按最低评分筛选 |
| 只看收藏 | 只显示收藏的作品 |
| 排序 | 评分 / 日期 / 标题 / 入库 / 收藏 等升降序 |
| 分页 | 上一页 / 下一页 / 每页数量（30/50 等） |

### 2. 作品卡片与详情抽屉

- 点击卡片打开**详情抽屉**：大图（封面/视频帧）、评分、名称、年月、制作组、标签、简介、观看状态、个人评分（点星星）、收藏（★）。
- 详情抽屉提供：播放（HTTP Range 流式）、下载、本地播放器打开（大文件守卫）、编辑标签、写笔记。

### 3. 消息通知（右上角 🔔）

- 任务完成 / 取消 / 失败、服务重启等会推送通知；小红点提示未读，点击查看详情（`logs.html?{id}` 看完整日志），可单条已读 / 全部已读。

## 二、播放页与推荐轮播（player.html）

从首页卡片详情抽屉点「播放」进入（新标签页打开 `player.html?id=…`）。

### 1. 播放窗口
- 视频铺满整个页面内容宽度，**与下方推荐区严格同宽同列**，最高占视口 76% 高度（`76vh`）。
- 音量跨作品、跨页面记忆（localStorage）；大文件会显示内存守卫提示。
- 顶栏显示文件名与 `#索引ID`；右下信息条展示「N 个标签 · 制作组 · 年份 · 候选总数」。

### 2. 推荐轮播（每页 2 行 × 6 列 = 12 格，不滚动）

| 元素 | 位置 / 行为 |
|------|------------|
| 卡片 | 点击即**在本页切换播放**（不跳页、不刷新），当前播放项描边高亮 |
| 封面角标 | 右上 ★评分；左上无；封面用 `contain` 渲染，**不放大不失真** |
| 理由徽章 | 卡片下方显示「N 个相同标签 / 同制作组 / 同期作品」，解释**为什么推荐它** |
| 自动轮播 | 默认开启，每 8 秒翻一页；鼠标悬停或键盘聚焦时**自动暂停**，离开后恢复；按钮可手动开关（记忆到 localStorage） |
| 翻页箭头 | 轮播两侧 `‹ ›`；只有一页时自动隐藏 |
| 圆点指示 | 底部圆点，点击直接跳页；下方显示「第 x / y 页」 |
| 换一批 | 用同样的打分规则换一个随机种子重新挑，推荐结果变化但质量不变 |
| 键盘 | ← / → 翻页（焦点在播放器上时不拦截，避免抢视频进度键） |

### 3. 推荐逻辑（为什么是这些作品）

按 8 个因子加权打分后排序，**分数越高越靠前**：

1. **标签重合度**（权重最高）——与当前作品共享标签越多越靠前；
2. 同制作组、同分类；3. 年代接近；4. 评分更高；5. 未看优先（看完的降权）；
6. 新入库小幅加成；7. 少量随机扰动，让「换一批」有新鲜感。

第 1 页是最相关的一批，第 2、3 页逐步降低相关度、增加探索；每页还限制了**同一制作组最多 3 格**，防止一个系列包场。

> 无障碍与响应式：支持 `prefers-reduced-motion`（系统开启减弱动效时默认不自动轮播）；窄屏自动降为 4 / 3 / 2 列，保证卡片可读。

## 三、白屏管理（右上角「白屏管理」）

进入后按标签页切换各功能：

### 1. 作品编辑

- **查询**：按关键词（标题/制作组/索引ID）、分类、封面/简介/标签是否有值、标签关键字、年份筛选。
- **下载索引ID.txt**：导出**当前查询结果**的作品索引ID（每行一个 id；不设条件 = 导出全部）。供联网补全 A 区「解析ID」使用。
- **编辑**：选择作品后填写标题/日文原题/制作组/年份/日期/评分/字幕/简介/**标签**/文件地址/海报地址，保存。
  - **标签输入框**：点击会弹出标签气泡（多选），应用后写回输入框，可继续手动编辑。
  - **本作品联网补全候选**：联网拉取该作品的简介/标签建议，可「采用并入库」。

### 2. 作品管理

- **分类管理**：当前分类下拉 + 新增 / 重命名（同步更新该分类下所有作品）/ 删除（仅允许删空分类）。
- **作品列表**：按分类 + 模糊查询（索引ID / 作品名称 / 标签）。
- **批量操作**（表头复选框全选当前列表，或逐行勾选）：
  - **删除选中索引**：仅从项目移除索引，**绝不删除磁盘文件**（重扫可恢复）。
  - **批量打标签**：弹出标签气泡多选，追加标签（保留原有、每作品 ≤10 个）。
  - **移动到分类**：把选中作品改到另一分类。

### 3. 联网补全

#### A · 全量联网补全
- 对缺失的作品自动回填**发布年月 / 简介 / 标签**（联网题材优先 → 本机简评兜底）。
- 可**上传索引ID文件**限定范围（不上传 = 全量缺失补全）；解析出的 ID 供 B 区复用。
- 尊重 `edited_fields` 人工编辑保护：已人工编辑过的字段**永不覆盖**。

#### B · 封面补全
- ① **本地匹配**：匹配库内 海报/封面/COVER/预告 目录素材。
- ② **联网搜索封面**：逐作品联网抓取下载（**必须先在 A 区解析索引ID**，否则提示步骤）。
- ③ **指定目录补全**：填本地目录，取图片与缺封面作品按标题匹配（只记录路径引用）。
- ④ **截图视频封面（标记）**：标记作品用视频预览帧当封面（前端实时取帧）。
- ⑤ **服务端抽帧**：用 **ffmpeg** 把已标记作品抽帧落盘小图、写回封面，之后前端改走普通图片加载（**首屏加载更快**）。推荐对 ④ 标记过的作品执行。

#### C · 人工审定（双栏）
- 左栏作品名列表，点击后右栏展示候选素材（前 10 张）。
- **有效行为**：点击候选图即选中（左栏「待修改」→「已修改」）。
- **批量提交修改**：提交所有已选图的行，成功后从左栏移除。
- 「刷新列表」按 **B 区最近一次联网封面范围**筛选；「重置列表」只清视图。
- 「重搜…」「拒绝吗」在右栏翻页控件左侧，用于单条处理。

### 4. 扫描

- 指定路径文件夹（留空需确认全盘）扫描入库。
- **分类下拉**：选分类后本次扫描到的作品一律记入该分类（不再按目录名推断）。
- 全盘扫描需勾选确认（防误触）。

### 5. 标签管理

- **新增 / 改名 / 删除**标签（删除需输入标签名解锁，防误触）。
- **导出标签**：`id,标签值` 纯文本 CSV（UTF-8 带 BOM，Excel/记事本可直接打开）。
- **导入标签**：增量（只增不删）/ 覆盖（清空重建，需输入 `__OVERWRITE__`，服务端自动备份到 `backups/`）。
- **标签恢复**：误覆盖/乱码后诊断、清理乱码标签、按简评痕迹重建关联、重跑打标。

### 6. 一键重启

- 输入确认词 `__RESTART__` + 二次确认后重启服务（改后端代码后用它生效）。

## 四、关键约束（务必知晓）

1. **只删索引不删文件**：删除作品/移动分类只改数据库索引，磁盘文件永不改动。
2. **编辑字段防覆盖**：人工编辑过的字段记入 `edited_fields`，联网补全永不覆盖。
3. **每作品标签 ≤10 个**：批量打标签/导入时超出部分自动跳过。
4. **全盘扫描 / 一键重启 / 覆盖导入** 均有二次确认，防止误操作。
