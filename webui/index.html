B · 封面补全

        

          为历史作品的封面做一次补齐，多种方式可组合使用：

          ① 本地匹配：匹配库内 海报 / 封面 / COVER / 预告 目录中的素材（可直接执行）；

          ② 联网搜索封面：逐作品联网抓取下载 —— 必须先在 A 区解析出索引ID才能执行
          （① 作品编辑 → 下载索引ID.txt → ② 在 A 区选择该文件并点「解析ID」→ ③ 解析成功后再执行），
          未解析时会提示步骤并阻止启动，避免误扫全库、耗时过长；

          ③ 指定目录补全：人工填写一个本地目录，从该目录取图片与缺封面作品按标题匹配
          （只记录路径引用，不复制/移动任何文件）；

          ④ 服务端抽帧：用 ffmpeg 给缺封面的作品抽帧落盘为小图（写回封面），
          之后前端改走普通图片加载 —— 首屏加载更快（30 张 <500ms）。
          与 ② 相同，必须先在 A 区解析出索引ID，只处理解析范围内当前没有封面的作品。
          （旧版「截图视频封面（标记）」已移除，由本功能替代。）

重复作品检测（按分类）

        

          选定分类后，按标题相似度自动把「看起来是同一部」的作品分到一组，人工确认后清理。

          【勾选逻辑】组头勾选框 = 本组全选 / 全不选；不勾选的完全不受删除影响，勾选了才会被删。

          【两种删除】「删除本组选中索引」只删索引与关联数据（标签 / 观看状态 / 评分 / 封面候选），磁盘文件不动；
          「删除本组选中作品（含文件）」会把勾选作品的视频文件一并从磁盘删除（二次确认，不可恢复，谨慎使用）。

          【相似度】阈值越大越严格（默认 0.86）；归一化后标题完全相同的一定会被分到同一组。

导入标签（增量 / 覆盖）

        

          文件格式为纯文本，每行一条：id,标签值（英文逗号分隔、换行分隔）；导出即该格式（UTF-8 带 BOM，Excel/记事本可直接正确打开），导入时由标签管理自行解析。

          【编码】导入按文件原始字节探测 UTF-8 / UTF-8-BOM / GBK / Big5，含乱码替换字符的文件会被直接拒绝，不会写入。

          【增量导入】只新增缺失标签，保留现有标签与全部作品关联；文件中的 id 未被占用则沿用，否则自动重新分配；

          【覆盖导入】需输入确认词 __OVERWRITE__，且服务端会先自动备份到 backups/ 目录，再清空重建（文件不含关联，关联会被解除）；

          标签值统一去空白并按上限截断。

标签恢复（误覆盖 / 乱码修复）

        

          若曾用「覆盖导入」写入过编码错误的文件，可在此诊断与恢复：

          ①「诊断」只统计、不改数据；②「清理乱码标签」删除名称含乱码替换符的标签及其关联；
          ③「按简评痕迹恢复」根据作品 meta 中留存的本机简评打标记录重建标签与关联；
          ④「重跑简评打标（忽略人工保护）」按磁盘简评文本重新生成标签（会覆盖已标记为人工编辑的标签，仅恢复场景使用）。
